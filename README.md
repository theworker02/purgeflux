# purgeflux

Purge validation gates for flux inputs before they hit prod.

**Site:** https://theworker02.github.io/purgeflux/

## Install / run

```bash
git clone https://github.com/theworker02/purgeflux.git
cd purgeflux
node src/cli.js
node --test
```
